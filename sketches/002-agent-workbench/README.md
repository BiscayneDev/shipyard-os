## Variant: Agent Workbench

### Design stance
Agent-native — the beautifului.dev primitive language applied to Shipyard: expandable thinking traces, tool chips, live task rows, and a composer with model picker as the centerpiece.

### Key choices
- Layout: 3-pane — icon rail / missions list with progress / chat workbench
- Typography: system sans + mono for tool calls and metrics
- Color: dark workbench, cyan tool accents, per-agent colors
- Interaction: collapsible thinking trace, hoverable tool chips, task-row status dots, follow-up chips

### Trade-offs
- Strong at: Harness-like feel, showing agent work as it happens, chat-first steering
- Weak at: first-run clarity — assumes the user already thinks in missions

### Best for
The operator who wants to watch and steer the fleet in real time, like a CI pipeline for agents.
