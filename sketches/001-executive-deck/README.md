## Variant: Executive Deck

### Design stance
Content-first calm — the dashboard is a single scrollable executive brief; everything else (fleet, decisions) is supporting cast.

### Key choices
- Layout: slim sidebar + single column, max-width reading measure
- Typography: system sans, large 16.5px brief copy, uppercase micro-labels
- Color: existing Shipyard dark (#09090d) + per-agent accent glows
- Interaction: sticky prompt bar, clickable decision rows, hover lift on agent cards

### Trade-offs
- Strong at: YC-wow first impression, clarity, "morning brief" ritual
- Weak at: density — power users must click into everything

### Best for
The captain who reads once, decides twice, and delegates the rest.
